Laptop Ledger - CS200 Project 1
Setup:   pip install -r requirements.txt
Run:     python main.py
Files:   main.py (entry), gui.py (PyQt5 UI), theme.py (3-colour theme), scraper.py (threaded scraper),
         extractors.py (page -> laptop records), parsers.py (spec parsing, CSV), sorting.py, searching.py
Data:    saved automatically to data/laptops.csv
